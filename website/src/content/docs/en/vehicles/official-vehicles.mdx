Official trucks are used through manually installed `.tpv` packages. <Ui id="home-new-project" /> and <Ui id="cmd-add-vehicle" /> list only installed vehicles. A package contains its templates and game data: after generation, installation, project creation and mod export need neither the game installation nor ConverterPIX.

## Generate packages

Package authors can use the Rust `tpv` command with [ConverterPIX](https://github.com/mwl4/ConverterPIX), an external executable:

```sh
mise exec -- cargo run --release -p tp-pack --bin tpv -- extract "/path/to/ETS2" \
  --converter "/path/to/converter_pix" --package-version 2.0.0
```

Replace the paths with your ETS2 installation and converter executable. Supply an explicit SemVer package version. Add `--vehicle man.tgx_2020` or `--vehicle daf.2021` to process one truck; omit it for every discovered truck. `--output <directory>` changes the parent directory of the batches.

The tool discovers official ETS2 trucks, including installed vehicle and tuning DLC. User mods, ATS and trailers are excluded. Each vehicle package contains all supported cabins and painted accessories. Cabin templates are 4096 × 4096; accessory dimensions come from the game's paint definitions. Main templates superpose compatible painted options.

Each run writes a unique subdirectory under `dist/` by default, holding valid packages and `report.json`. Intermediates and converter logs stay under `target/`. Incomplete or ambiguous vehicles, unsupported shaders and unsupported UV mappings are refused. Other vehicles continue; any failure makes the command exit unsuccessfully. No partial vehicle package is published.

The report records sources, versions, texture coverage, successes, failures and limits. Technical package validation does not prove correctness in game: new vehicles and new configurations still need game checks.

`missing_dependencies` lists missing references and their source definitions when available. `expected_dlc: null` with `dlc_origin: "unknown"` means the required DLC cannot be identified; the archive mentioning a reference does not establish which DLC supplies it.

Paint overrides pointing to accessories with no installed definition are excluded and reported with `disposition: "ignored_reference"`; they do not prevent package generation. Defined accessories with unusable geometry or dimensions, and required missing files, still block extraction (`disposition: "blocking"`).

Supported paint shaders are `truckpaint`, `truckpaint.tsnmap` and `truckpaint.tsnmapuv`, with optional `airbrush`, `flipflake` and `altuv` flavors and `.a` or `.asafew.a` alpha-test suffixes. Templates trace the mesh UVs; they do not reproduce per-pixel opacity masks. Visible painted cabin materials must agree on one UV mode. The extractor uses that mode for every accessory and records it in the package for mod export. Missing or ambiguous selected UV mappings and conflicting cabin modes are refused. Materials tinted only by the base paint color do not establish a paint-job UV mapping; an override targeting such a defined accessory remains a coverage failure.

Finite UV coordinates outside [0, 1] are preserved, without wrapping, clamping or switching channels. The SVG viewport limits the visible wireframe to the texture. The report records `uv_bounds` and `out_of_bounds_vertices`; these surfaces need particular attention in game. Non-finite or unrepresentable coordinates remain invalid.

`dimension_diagnostics` lists every accessory with missing or conflicting crop dimensions, the candidate sizes, masks and referencing definitions/archives. Shared fill masks do not establish a useful template resolution. These cases remain blocking; the extractor does not invent dimensions.

## Install and paint

1. Open the [Vehicle Library](../library/) and use <Ui id="vehicles-install" /> to choose a generated `.tpv`.
2. In <Ui id="home-new-project" />, check that installed vehicle, choose cabins and accessories, then use <Ui id="new-project-create" />.
3. Paint and save the project, then follow [Mod export](../../export/mod/).

<Shot name="vehicles/library" alt="The Vehicle Library with installed packages and the Install button" />

Keep packages for future installation. The game and converter are needed only for generation. Custom vehicles and sample packages remain available.

## Retired packages

The Carsmaniac catalog and template pack workflow have been removed. Generated packages keep `official.ets2.<vehicle>`, including `official.ets2.daf.2021`. Remove old test packages manually before installing the generated replacements. There is no migration of old placements. Installing the same id and version replaces that installed version; another version is kept alongside it. Existing project files are not automatically rewritten.
