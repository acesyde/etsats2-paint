TruckPaint connaît les données de jeu des véhicules officiels : leurs cabines, leurs accessoires et leur place dans les fichiers du jeu. Vous n’avez rien à saisir. Ce que TruckPaint ne fournit pas, ce sont les gabarits, qui appartiennent à SCS Software. Il les prend dans le **pack de gabarits** réalisé par Carsmaniac, que vous téléchargez une fois par jeu.

## Les véhicules disponibles

Les véhicules officiels sont listés en premier dans <Ui id="home-new-project" /> et dans <Ui id="cmd-add-vehicle" />, sous <Ui id="vehicles-section-official" />, qu’ils soient installés ou non. Pour l’instant, le catalogue contient deux véhicules ETS2 :

- le **DAF NGD**, un camion avec trois dispositions de cabine (XG+, XG et XF) et quatre accessoires : pare-soleil, jupes latérales, rétroviseurs standard et rétroviseurs caméra ;
- la **Krone Cool Liner**, une remorque dont la texture de caisse (8192 × 1024) peint aussi les accessoires de caisse, avec quatre accessoires de châssis. Son pare-chocs arrière est laissé de côté : le pack n’a pas de gabarit pour lui.

D’autres véhicules des deux jeux seront ajoutés par lots. La liste ne nécessite aucun accès au réseau.

## Installer votre premier véhicule officiel

La première fois que vous cochez un véhicule officiel d’un jeu, TruckPaint demande le pack de gabarits de ce jeu.

1. Dans <Ui id="home-new-project" /> ou <Ui id="cmd-add-vehicle" />, cochez un véhicule officiel, par exemple le DAF NGD. La boîte de dialogue du pack de gabarits s’ouvre.
2. Cliquez sur <Ui id="pack-open-download" />. Votre navigateur web ouvre le sujet du pack sur le forum de SCS Software. Si le navigateur ne s’ouvre pas, cliquez sur <Ui id="pack-copy-link" /> et collez le lien dans votre navigateur.
3. Téléchargez le pack. Il pèse environ 1,2 Go, et un seul pack sert pour tous les véhicules du jeu.
4. Décompressez-le où vous voulez sur votre ordinateur.
5. De retour dans TruckPaint, cliquez sur <Ui id="pack-choose-folder" /> et choisissez le dossier décompressé, ou déposez le dossier sur la boîte de dialogue.

<Shot name="vehicles/template-pack" alt="La boîte de dialogue du pack de gabarits affichée après avoir coché le DAF NGD, avec les étapes pour télécharger, décompresser et choisir le pack" />

TruckPaint affiche « Installation de… » pendant qu’il crée le véhicule à partir des fichiers du pack, avec un bouton <Ui id="button-cancel" />. Le véhicule est ensuite coché comme n’importe quel véhicule installé : sa première texture principale et tous ses accessoires sont cochés.

Le dossier choisi peut être le dossier du pack lui-même ou celui dans lequel vous l’avez décompressé. S’il ne contient pas le pack de ce jeu, TruckPaint vous le dit et vous le redemande.

## Les fois suivantes

TruckPaint mémorise le dossier du pack de chaque jeu. Choisir un autre véhicule officiel l’installe directement, sans rien demander.

Un véhicule officiel installé n’a plus besoin du pack : il continue de fonctionner dans vos projets et dans les listes même si vous déplacez ou supprimez le pack. Si le pack a disparu quand vous installez un autre véhicule officiel, la boîte de dialogue du pack de gabarits s’ouvre à nouveau et indique que le dossier a été déplacé ou supprimé.

Pour changer ou oublier le dossier d’un pack, ouvrez <Ui id="home-preferences" /> et allez dans <Ui id="prefs-template-packs" /> : <Ui id="prefs-pack-choose" /> choisit un autre dossier (par exemple le pack d’une version plus récente du jeu) et <Ui id="prefs-pack-clear" /> l’oublie. Ni l’un ni l’autre ne modifie les véhicules déjà installés ni vos projets. Un dossier qui n’existe plus affiche <Ui id="prefs-pack-missing" />.

## Quand une installation échoue

Rien n’est installé, et un message en donne la raison, quand :

- un fichier dont le véhicule a besoin manque dans le pack : le message nomme le véhicule et le fichier ;
- un gabarit n’a pas la taille attendue : le pack correspond peut-être à une autre version du jeu. Téléchargez le pack qui correspond à votre jeu.
